
# SEC-001 — Remote Workforce Security

**Rigel Meridian Systems | Security Engineering Project**

!!! info "Project Status: In Progress"
    This project documents the planned security modernization of 22 remote employee workstations. Controls are documented as proposed, implemented, or validated based on actual homelab progress.

## Project Overview

| Field | Details |
|---|---|
| Project ID | SEC-001 |
| Project Name | Remote Workforce Security |
| Organization | Rigel Meridian Systems |
| Project Owner | Security Manager |
| Environment | Proxmox Enterprise Homelab |
| Scope | 22 remote Windows workstations |
| Status | In Progress |

## Project Objectives

- Establish centralized endpoint management.
- Modernize authentication using Microsoft Entra ID.
- Implement phishing-resistant authentication.
- Enforce BitLocker full-disk encryption.
- Reduce unnecessary administrative privileges.
- Establish endpoint compliance and patch management.
- Improve security logging and monitoring.
