# Rigel Meridian Systems — Company Profile

> **Disclaimer:** Rigel Meridian Systems (RMS) is a fictional organization
> created for a cybersecurity homelab and portfolio project. It does not
> represent a real company or production environment.

## Company Overview

**Company:** Rigel Meridian Systems, Inc. (RMS)  
**Industry:** Aerospace and Defense Technology  
**Employees:** Approximately 75  
**Remote Workforce:** Approximately 22 employees regularly work remotely  

Rigel Meridian Systems develops software and data-analysis solutions for
commercial and aerospace customers.

The organization has historically operated without a dedicated cybersecurity
team. Security responsibilities were primarily handled by the Systems
Administrator alongside normal IT operations.

As the organization has grown and acquired larger customers, leadership has
identified the need for a formal cybersecurity program.

## Current Environment

At the beginning of the security modernization project, RMS operates:

- An on-premises Active Directory environment
- Windows 11 employee workstations
- Windows and Linux servers
- Microsoft 365 for email and productivity
- VPN-based remote access
- Internal file storage containing customer information
- Several internal business applications
- A public-facing company website

Developers use a combination of Windows and Linux systems.

## Initial Security Posture

The initial assessment identified several areas requiring improvement:

- Remote VPN authentication relies primarily on usernames and passwords
- Multi-factor authentication is not universally enforced
- Endpoint management and patch visibility are limited
- Some employees possess local administrator accounts
- Security logs are distributed across systems and are not routinely reviewed
- No dedicated Security Operations Center (SOC) exists
- No formal incident-response process exists
- Employees have reported receiving phishing emails

## Security Program Objective

The objective of the RMS Security Program is to design, implement, test,
and document a practical enterprise security architecture that protects
company systems and data while allowing employees to perform their jobs
effectively.

The environment will be developed incrementally based on business
requirements, risk assessments, security incidents, and lessons learned.
